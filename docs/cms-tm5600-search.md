# Поиск CMS под TM5600 (для C1VP) — результат

Искал публичный образ/апдейтер CMS для TM5600: archive.org (scrape API), FTP HP/Compaq,
сайты Sony/Fujitsu/NEC, форумы, LKML. Вывод — **публичного отдельного обновления CMS под
TM5600 нет**.

## Что есть

- **Единственный публичный образ CMS — TM5800** (`cms4.4.03raptor.cru`, HP SoftPaq SP23689).
  HP, похоже, единственный OEM, выпустивший полевой апдейтер CMS (для планшета TC1000).
- **Ветка 4.4.x — только TM5800** (требование даташита TM5800). Для TM5400/TM5600 потолок —
  ветка 4.3.x.
- **Последняя версия CMS под TM5600, засвидетельствованная где-либо — 4.3.2** (научные статьи
  про Bladed Beowulf на TM5600: 4.2.6 → 4.3.2 от RLX Technologies; владельцы в LKML сообщали
  4.3.x). Самого файла в открытом доступе нет.

## Тупики

- **OQO Crusoe PTT / `tminfo.msi`** (archive.org, «Transmeta CPU Utilities») — это служба
  Persistent Translation Technology (сохранение кэша трансляций в Windows) версии 2.0.13 и
  утилита вывода версии, **а не образ CMS**. Тот же компонент лежал внутри SP23689
  (`F1870_CrusoePTTen.msi`). Образа `.cru` там нет.
- **Recovery-диски TM5600-машин** (Sony Vaio C1MR/U1, Casio FIVA, NEC LaVie LZ — всё на
  archive.org) восстанавливают Windows и драйверы. CMS на этих машинах зашит на заводе и
  OEM-апдейтером не обновлялся, поэтому `.cru` там ожидать не стоит. Образы по 400–700 МБ,
  не качались.
- **BIOS Sony** (в т.ч. распакованные ранее) CMS не содержат — проверено.

## Реальные пути к свежему CMS для C1VP

1. **Сначала узнать, что уже стоит**: строка «Code Morphing Software revision …» из `dmesg`
   (Linux) на C1VP. Это и есть гарантированно совместимая версия.
2. **Поднять версию можно только дампом с другой TM5600-машины** на свежем 4.3.x и прошивкой
   программатором в последовательный флеш `SROM` — и только при совпадающем степпинге
   (CPUID / `IoctlCMSGetPSNID`). Штатного пути нет: Sony апдейтер CMS не выпускала, а чужой
   OEM-апдейтер подписан под свою платформу.
3. Образ CMS не привязан к плате (настройка платы — в отдельном конфиг-EEPROM), поэтому
   донором теоретически может быть любая TM5600-машина с тем же степпингом, не обязательно Sony.
